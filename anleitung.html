Inselspiel

So kommt das Spiel auf deinen Home-Bildschirm – dann startet es im Vollbild wie eine App.

timoomit2026.github.io/ferienprojekt-spiel ▶ Zum Spiel
📱 iPhoneneues Safari – Adressleiste unten mit ☰ links▶
  1. Den Link in Safari öffnen.
  2. Unten in der Adressleiste links auf das Symbol mit den Strichen tippen (manchmal sind es drei Punkte ••• rechts).
  3. Auf „Teilen“ tippen . Steht es nicht da: erst auf „Mehr“.
  4. Nach unten wischen → „Zum Home-Bildschirm“.
  5. „Als Web-App öffnen“ eingeschaltet lassen → „Hinzufügen“.
📱 iPhoneälteres Safari – Teilen-Symbol unten in der Mitte▶
  1. Den Link in Safari öffnen.
  2. Unten in der Mitte auf das Teilen-Symbol tippen (Viereck mit Pfeil nach oben).
  3. Nach unten wischen → „Zum Home-Bildschirm“.
  4. Oben rechts auf „Hinzufügen“.
📲 iPadSafari▶
  1. Den Link in Safari öffnen.
  2. Oben rechts neben der Adresse auf das Teilen-Symbol tippen. Nicht da? Dann auf ••• oder ☰ neben der Adresse und dort auf „Teilen“.
  3. Nach unten wischen → „Zum Home-Bildschirm“.
  4. „Hinzufügen“ antippen.
🤖 AndroidChrome (Samsung, Pixel, …)▶
  1. Den Link in Chrome öffnen.
  2. Oben rechts auf die drei Punkte ⋮ tippen.
  3. „Zum Startbildschirm hinzufügen“ wählen (manchmal heißt es „App installieren“).
  4. „Hinzufügen“ / „Installieren“ bestätigen.
Samsung-Internet: unten rechts auf ☰ → „Seite hinzufügen zu“ → „Startbildschirm“.
💻 ComputerMac oder Windows▶

Einfach den Link im Browser öffnen – fertig.

  • Laufen: W A S D oder Pfeiltasten
  • Umschauen: Maus gedrückt ziehen
  • Springen: Leertaste · Aktion: E · Rucksack: R

✅ Gut zu wissen

  • Immer über das neue Symbol starten und das Gerät quer halten.
  • Das Spiel speichert von selbst – auf deinem Gerät. Kein Konto, keine Anmeldung.
  • Nicht im privaten Modus spielen, sonst ist der Spielstand weg.
  • Ton an! 🎵 Links Finger hinlegen und schieben = laufen, rechts wischen = umschauen.
  • Oben links im Aufgabenbuch 📋 steht, was als Nächstes dran ist.
