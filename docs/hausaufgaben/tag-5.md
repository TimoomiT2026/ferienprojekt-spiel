# 🏠 Abschluss-Hausaufgabe: Die Code-Schatzsuche 🗺️

Diese Woche hast **du** entschieden, wie das Spiel sein soll – und die KI hat es gebaut.
Aber wo stehen deine Ideen eigentlich? Sie sind **Text in Dateien**! Heute gehst du auf Schatzsuche im Code.

Du brauchst: Papa, den Mac, ca. 45 Minuten.

---

## 1. Schatzsuche im Code 🔍 (20 Minuten)

Öffnet auf GitHub das Projekt: **github.com/timoomit2026/ferienprojekt-spiel**
Dort kann man alles lesen, ohne etwas kaputt zu machen.

Finde diese Schätze. Schreib die **Zeilennummer** auf (die steht links neben dem Code):

| Schatz | In welcher Datei suchen? | Zeile |
|---|---|---|
| 🔴 Der Name „Insadorium“ | `js/vorgeschichte.js` | ____ |
| 🐴 Nach wie vielen Tagen ohne Futter reißt das Pferd aus? | `js/einstellungen.js` (such nach `pferdAusreissTage`) | ____ |
| 🧒 Der Name „Mucko“ | `js/bewohner.js` | ____ |
| 🤿 Ab dem wievielten Bewohner gibt es die Taucherbrille? | `js/einstellungen.js` (such nach `brilleFruehestens`) | ____ |
| 🪙 Wie viel Geld hat man am Anfang? | `js/einstellungen.js` (such nach `startGeld`) | ____ |

💡 **Tipp:** Die Sätze hinter `//` sind **Kommentare**. Die liest der Computer nicht – die sind für dich! Lies ein paar davon.

---

## 2. Selbst an einer Zahl drehen 🔧 (20 Minuten)

Jetzt wirst du selbst Programmierer! Damit das Spiel deiner Freunde nicht kaputtgeht,
macht ihr eine **Kopie** auf dem Mac.

**Papa macht das (einmal):**
1. Auf GitHub: grüner Knopf **„Code“** → **„Download ZIP“**. Die ZIP-Datei doppelklicken (entpacken).
2. Das Programm **Terminal** öffnen und eintippen (den Ordnernamen anpassen):
   ```
   cd ~/Downloads/ferienprojekt-spiel-main
   python3 -m http.server
   ```
3. Im Browser öffnen: **http://localhost:8000**

**Jetzt du:**
Öffne die Datei `js/einstellungen.js` (Rechtsklick → Öffnen mit → TextEdit).
Ändere **eine** Zahl, speichere, und lade das Spiel im Browser neu. Was passiert?

| Zahl | Steht da | Probier mal | Was ist passiert? |
|---|---|---|---|
| `sprungKraft` | 7 | 20 | |
| `laufTempo` | 7 | 2 | |
| `tagMinuten` | 5 | 1 | |
| `startGeld` | 30 | 999 | |

🧪 Das nennt man **Experimentieren**: Eine Sache ändern, schauen, was passiert. So arbeiten echte Spieleentwickler jeden Tag!

Schreib auf:
- **Was habe ich diese Woche gemacht?** (z. B. „Ich habe mir das Insadorium ausgedacht“)
- **Was hat die KI gemacht?**
- **Was war meine beste Idee?**

---

### 📖 Neue Wörter fürs Lexikon
- **Kommentar:** Ein Satz im Code, den nur Menschen lesen, nicht der Computer.
- **Experimentieren:** Etwas ausprobieren und schauen, was passiert.
- **Kopie / lokal:** Das Spiel läuft nur auf deinem Computer – niemand sonst sieht deine Änderungen.
