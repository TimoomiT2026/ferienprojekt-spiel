# Wochenplan & Aufgaben

Jeden Tag **1 Stunde** zusammen. So läuft eine Session ab:

1. **10 Min:** Was ist neu im Spiel?
2. **30 Min:** Spielen und Fehler in die [Fehlerliste](fehlerliste.md) schreiben
3. **10 Min:** Ein Lernthema
4. **10 Min:** Hausaufgabe besprechen

Zwischen den Sessions baut Claude die nächste Version.
