# Die Spielidee

So haben wir es am Tag 1 aus der Mindmap herausgearbeitet.

## In einem Satz
Man ist allein auf einer Insel, gräbt nach Schätzen, handelt im Dorf, baut sich ein Lager und muss sich vor den Monstern in der Nacht schützen.

## Wie es aussieht
- 3D, **nicht eckig**: runde, weiche Comic-Formen, so wie Fortnite oder Farm Together
- Gespielt wird auf dem **iPad**

## Die drei wichtigsten Dinge (Entscheidung vom Game Designer)
1. **Schlafen**, weil die Monster sonst angreifen. Die kommen nämlich nur nachts.
2. **Sachen abbauen**, mit der Schaufel graben.
3. **Mit Leuten handeln**, weil man sonst keine Materialien für sein Lager hat. Die Dörfer muss man erst finden!

## Der Spiel-Kreislauf („Game Loop“)

```
☀️ TAG                                   🌙 NACHT
graben → Steine/Schätze finden            Monster kommen
   ↓                                          ↓
Dorf finden → verkaufen → Münzen          im Zelt / Haus schlafen = sicher
   ↓                                          ↓
Holz + Feuer kaufen → Lager bauen   →→→   nächster Morgen  →→→ wieder von vorn
```

## Regeln, die schon feststehen
- Startgeld: **100 Münzen**
- Am Anfang hat man nur ein **Zelt**
- Später kann man **Häuser** aus Holz oder Stein bauen
- Für ein **Lagerfeuer** braucht man Holz und Feuer, und das gibt's nur durch Handeln
- Gegraben wird an **Grabestellen** (die Welt selbst bleibt rund und schön)
- **Monster: ja**, aber nur nachts

## Noch offen (Hausaufgabe!)
- Was kostet was im Dorf? → Preisliste
- Wie sieht die Insel von oben aus? → Karte malen
- Wie heißt das Spiel?
- Gibt es ein Ziel, oder spielt man einfach immer weiter? (In der Mindmap steht „Ziel: keines“.)

## Das geheime Material: Insadorium 🔮
Der Forscher sucht auf der Inselgruppe nach dem **Insadorium**. Den Namen hat der Game Designer an Tag 3 erfunden.

So sieht es aus (Entscheidung vom Game Designer):
- Ein **Stein**, **rot**, der so **grell leuchtet**, dass man fast nicht hineinschauen kann
- Er liegt **unter Wasser**
- Wer ihn findet, hat das **Ziel erreicht**: Konfetti über den ganzen Bildschirm und eine Dankeschön-Nachricht fürs Spielen. Danach kann man ganz frei weiterspielen (Open World).
