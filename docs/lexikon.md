# Lexikon – Wörter, die wir gelernt haben

| Wort | Was es bedeutet |
|---|---|
| **Mindmap** | Eine Gedanken-Landkarte: in der Mitte das Thema, außen herum alle Ideen, mit Linien verbunden. |
| **Game Designer** | Die Person, die erfindet, *wie* ein Spiel funktioniert: Regeln, Ziele, was Spaß macht. |
| **Game Loop** (Spiel-Kreislauf) | Das, was man im Spiel immer wieder macht. Bei uns: graben → handeln → bauen → Nacht überleben → von vorn. |
| **Spielschleife** | Der Computer macht 60 Mal pro Sekunde: Eingabe lesen → alles bewegen → Bild malen. Steht in `js/main.js`. |
| **Prototyp** | Eine erste, einfache Version zum Ausprobieren. Sieht noch nicht fertig aus, zeigt aber, ob die Idee funktioniert. |
| **Backlog** | Die Warteliste für Ideen, die später kommen. |
| **Bug** | Ein Fehler im Spiel. |
| **Feedback-Schleife** | Spielen → sagen, was stört → reparieren → wieder spielen. Je öfter, desto besser wird das Spiel. |
| **Inventar** | Der Rucksack im Spiel: Liste von allem, was man dabei hat. |
| **Chunk** (Stück) | Die Welt wird in Quadrate geteilt. Gemalt werden nur die in der Nähe, damit das iPad nicht ins Schwitzen kommt. |
| **Dreiecke** | Alles im 3D-Spiel ist aus winzigen Dreiecken gebaut. Ein Baum hat ein paar hundert. Zu viele machen das Spiel langsam. |
| **Textur** | Ein Foto, das wie eine Tapete auf eine 3D-Form geklebt wird. Unser Gras, die Felsen und die Rinde sind echte Fotos. |
| **Blätter-Karte** | Eine Fläche mit einem Bild von vielen Blättern. Das Durchsichtige wird weggeschnitten. Ein Baum hat ca. 46 davon. Viel schneller als jedes Blatt einzeln! |
| **CC0** | Eine Erlaubnis: Diese Bilder darf jeder kostenlos benutzen. Unsere Texturen sind CC0 (von ambientCG). |
| **Rezept** | Eine Bauanleitung: Was man an der Werkbank braucht, um etwas zu bauen. Steht in `einstellungen.js`. |
| **Story** (Geschichte) | Gibt dem Spiel ein Ziel. Bei uns: Ein Forscher sucht ein geheimes Material auf einer Inselgruppe. |
| **Wirtschaft** | Wie Geld im Spiel fließt: verkaufen → Münzen → kaufen. Stimmen die Preise nicht, ist das Spiel zu leicht oder zu schwer. |
| **Haltbarkeit** | Wie oft man etwas benutzen kann, bevor es kaputtgeht. |
| **Spielstand** | Alles, was man erreicht hat, wird gespeichert, damit man weiterspielen kann. |
| **Etappe** (Meilenstein) | Ein großes Stück Arbeit, das man fertig macht, bevor man das nächste anfängt. |
| **Balancing** | Ein Spiel so einstellen, dass es nicht zu leicht und nicht zu schwer ist. Zum Beispiel: Startgeld 30 statt 100. |
| **Quest-Kette** | Aufgaben, die aufeinander aufbauen. Unser Aufgabenbuch 📋 ist eine. |
| **Skelett & Skinning** | Unser Junge hat unsichtbare Knochen. Die Haut (Pulli, Hose) biegt sich mit, wenn sich Knie und Ellbogen bewegen. |
| **Bloom** | Helle Dinge (Feuer, Mond, Sonne) leuchten weich über ihren Rand hinaus – wie in echt in der Kamera. |
| **Nachbearbeitung** | Das fertige Bild wird noch einmal „gefiltert“: Farben, Leuchten, dunkle Ecken (Vignette). Wie ein Instagram-Filter fürs Spiel. |
| **Atlas** | Viele kleine Bilder (z. B. 4 Laubsorten) in einem großen Bild. Spart Arbeit für das iPad. |
| **Gerstner-Wellen** | Eine Rechenformel für echte Meereswellen, benannt nach einem Forscher von vor über 200 Jahren. |
| **Angebot & Nachfrage** | Wenn viele dasselbe verkaufen, wird es weniger wert. Darum zahlt der Händler für den 10. Stein weniger als für den ersten. |
| **Upgrade** | Etwas verbessern, z. B. das Zelt zur Hütte ausbauen. |
| **Freischalten** | Etwas wird erst möglich, wenn man etwas geschafft hat (Pferdestall erst ab Hütte und Tag 3). |
| **Seed** | Eine Zahl, aus der die Welt „zufällig“ gebaut wird. Gleicher Seed = gleiche Welt. Unser Seed: 42. |
| **Tutorial** | Eine Anleitung im Spiel selbst. Bei uns: kleine Sprechblasen, die etwas erklären, wenn man es zum ersten Mal sieht. |
| **Playtest** | Andere Leute (z. B. Freunde) spielen das Spiel zum ersten Mal, und man schaut, wo sie hängen bleiben. Dafür haben wir das Tutorial gebaut. |
| **Recycling** | Aus Müll etwas Neues machen: Aus dem alten Schuh vom Angeln wird eine Pferde-Leine. |
| **Trigger** | Ein Auslöser: Etwas passiert erst, wenn vorher etwas anderes passiert ist. Bei uns: Erst wenn die Person mit der Taucherbrille von den Münzen erzählt, gibt es die Münz-Hügel. |
| **KI-Gegner / NPC** | Figuren im Spiel, die der Computer steuert, zum Beispiel die Inselbewohner. NPC heißt „Non-Player Character“ – keine echte Person spielt sie. |
| **Finale** | Das große Ende eines Spiels. Bei uns: Konfetti und ein Dankeschön, wenn man das Insadorium findet. |
