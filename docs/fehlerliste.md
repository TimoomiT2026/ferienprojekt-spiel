# Fehlerliste 🐞

Hier schreibt der Chef-Tester alles rein, was komisch ist, nervt oder kaputt ist.
Fehler im Spiel heißen **„Bugs“** (englisch für Käfer).

**So schreibt man einen guten Fehler auf:**
1. Was hast du gemacht?
2. Was ist passiert?
3. Was hätte passieren sollen?
